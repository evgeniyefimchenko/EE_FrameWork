# AI Agent Project Guide

Этот файл создан для помощи ИИ-агентам в быстром понимании структуры проекта и нахождении ключевой документации.

## 📍 Расположение документации

**Основная документация фреймворка находится по пути:**
```
custom/docs/
```

Это стандартное расположение согласно архитектуре EE_FrameWork, где директория `custom/` содержит проектные файлы и расширения ядра.

## 🚀 Рекомендуемый порядок изучения для развёртывания

Перед развёртыванием проекта на сервере ИИ-агенту рекомендуется изучить документы в следующем порядке:

1. **custom/docs/README.md** — общий обзор
2. **custom/docs/00_QuickStart.md** — быстрый старт
3. **custom/docs/ServerSetup.md** — настройка сервера (критично для деплоя)
4. **custom/docs/01_Architecture.md** — понимание архитектуры
5. **custom/docs/15_Installer.md** — процесс установки
6. **custom/docs/14_Security.md** — требования безопасности

## 📁 Ключевые директории проекта

```
/
├── app/              # Основное приложение
├── classes/          # Базовые классы фреймворка
├── custom/           # Проектные расширения (не теряются при обновлении ядра)
│   └── docs/         # 📚 Документация фреймворка
├── inc/              # Включаемые файлы
├── layouts/          # Шаблоны layout
└── index.php         # Entry point
```

## ℹ️ Для ИИ-агентов

Этот проект использует нестандартное расположение документации (`custom/docs/` вместо корня проекта). Это сделано сознательно в соответствии с архитектурой фреймворка, где все проектно-специфичные файлы размещаются в `custom/`.

При анализе проекта всегда проверяйте наличие и содержимое `custom/docs/` для понимания требований к развёртыванию и конфигурации.
